# Pizdun

Desktop-приложение (Electron) для созвонов: пишет микрофон и голос собеседников,
потоково расшифровывает речь через **whisper.cpp**, по ходу разговора вычленяет факты
через любой OpenAI-совместимый LLM API, а после звонка собирает итоги.
Расшифровка, факты и итоги складываются в markdown-файлы — по папке на созвон.

## Установка

```bash
npm install
```

`postinstall` сам ставит whisper.cpp: на Windows и Linux качает готовые бинари из релиза,
на macOS собирает из исходников (если в системе нет `cmake`, скачивает официальную сборку Kitware).
Нужен только компилятор — на macOS это Xcode Command Line Tools.

Если установка не удалась, `npm install` не падает: путь к бинарю можно указать вручную
в настройках, а повторить попытку — через `npm run setup:whisper`.

## Запуск

```bash
npm start
```

Дальше в настройках (⚙):

1. **Модель распознавания** — выбери в списке, приложение скачает само.
   По умолчанию рекомендуется `large-v3-turbo-q5_0` (574 МБ).
2. **LLM** — URL OpenAI-совместимого API и токен. Без них не будет фактов и итогов,
   расшифровка работать будет.

## Сборка

```bash
npm run build:mac     # dmg + zip
npm run build:win     # nsis
npm run build:linux   # AppImage + deb
```

Собирается под платформу хоста: бинарь whisper.cpp ставится только под текущую ОС и архитектуру.
Для матрицы платформ нужен CI с раннерами на каждую.

## Системный звук на macOS

Голос собеседников берётся через loopback и требует разрешения «Запись экрана и системного звука».
Запрос появляется при первой попытке записи; если его не было — ⚙ → «Сбросить и спросить заново»
(или `tccutil reset ScreenCapture dev.pizdun.app`), затем перезапустить приложение.
Без разрешения созвон всё равно пишется, но только с микрофона.

Проверить, что захват работает: `npm run check:audio`.
